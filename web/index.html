Comparison rules

Indentation, blank lines, whitespace-only text between tags, comments, processing instructions, and attribute order are ignored.

Element names, attributes, meaningful text, and child order are compared. Spaces inside values remain significant, subject to XML parser normalization.

Namespace prefixes on names are resolved; prefixes inside values such as type="xs:string" are compared literally. Paths show namespace URIs in braces.

This compares the selected documents, not full schema equivalence or XSD validity. Imports and includes are not expanded. Inserted or reordered elements can produce multiple differences.
